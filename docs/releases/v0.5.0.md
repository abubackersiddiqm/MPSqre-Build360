# MPSqre Build360 v0.5.0

## Scope

Phase 5: Projects, WBS, Tasks, Project Baselines, Design Control, Design Reviews and Issues, Transmittals, Estimation, Versioned BOQ and Estimate Baselines.

## Database

Adds `projects.0001_initial`, `design.0001_initial`, `estimation.0001_initial`, and `identity.0005_phase5_delivery_permissions`.

## Local runtime

The release preserves the native Windows no-Docker workflow. PostgreSQL remains the only required local service. Cache and background execution use the existing local-development safeguards.

## Operational sequence

Apply source, verify, back up PostgreSQL, run migrations, initialize Phase 5 stages and permissions, run backend and frontend quality gates, then start both applications and execute the Phase 5 smoke test.
