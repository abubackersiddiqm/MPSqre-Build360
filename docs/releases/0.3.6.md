# MPSqre Build360 0.3.6

## No-Docker local runtime

This release adds an explicitly local-only runtime mode for Windows development
without Docker, Redis, MinIO, or Celery workers.

When `LOCAL_NO_DOCKER=true` and `APP_ENV=local`:

- Django uses `LocMemCache` for request throttling and local cache operations.
- Celery tasks execute eagerly in the Django process.
- PostgreSQL remains mandatory and is read from `DATABASE_URL`.
- Production behavior is unchanged.

The mode is rejected outside `local` and `test` environments to prevent accidental
production use. Local-memory throttles are process-local and are not an enterprise
substitute for Redis.
