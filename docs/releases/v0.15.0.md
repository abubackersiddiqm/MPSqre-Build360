# MPSqre Build360 v0.15.0

Phase 15 introduces the unified permission-aware application shell and mobile PWA experience.

## Included

- Desktop workspace sidebar and mobile bottom navigation
- Capability-filtered workspace registry
- Ctrl/Cmd+K command palette and recent workspace ordering
- Notification unread badge and tenant/account controls
- Authorized workspace catalogue
- PWA manifest, icons, production service-worker registration and offline boundary
- Platform dashboard consolidation
- Accessibility and reduced-motion hardening

## Security boundary

The service worker caches only static Next.js assets, PWA icons and the public offline page. It does not cache API requests or authenticated HTML pages.

## Database

No database migration is required.
