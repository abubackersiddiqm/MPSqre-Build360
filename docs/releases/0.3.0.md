# MPSqre Build360 0.3.0 — Platform Controls

Release date: 30 July 2026

## Included

- Versioned, schema-validated company configuration.
- Immutable published workflow definitions and version-pinned instances.
- Approval inbox, effective permissions, and optimistic concurrency.
- Versioned subscription plans and effective-dated entitlement overrides.
- Private object-storage upload/finalize/download governance.
- Checksum and malware-scan gates.
- Tenant-scoped audit search.
- Outbox claiming, retry, publication, and dead-letter controls.
- Permission-aware Phase 3 platform summary UI.
- Additive database migrations and Phase 3 permission seeds.

## Explicitly deferred

- Business CRM/project/procurement modules.
- Provider-specific notification publishers.
- Full configuration studio editors.
- Malware scanning worker/provider adapter.
- PostgreSQL row-level security.
- Production backup/restore and dead-letter operating runbooks.

## Upgrade notes

- Merge the new object-storage public endpoint and file-limit environment
  variables into the existing `.env`.
- Apply database migrations before starting application traffic.
- Assign Phase 3 permissions to controlled tenant roles; migrations do not grant
  them automatically.
- Never use `docker compose down -v` during an upgrade because it deletes local
  PostgreSQL, Redis, and MinIO volumes.
