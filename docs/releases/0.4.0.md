# MPSqre Build360 0.4.0 — CRM customer spine

## Delivered

- Configurable tenant-specific lead and opportunity stages
- Customers and protected contacts
- Application-level email and phone encryption
- Tenant-scoped blind-index duplicate detection
- Permission-gated and audited contact reveal
- Lead creation, assignment, follow-up and stage history
- Opportunity pipeline with weighted values
- Calls, meetings, follow-ups, notes and site visits
- Optimistic concurrency for stage transitions
- Idempotent lead conversion snapshot
- Immutable audit and transactional outbox facts
- Responsive CRM workspace for desktop, tablet and mobile
- Native Windows no-Docker setup, migration, initialization and test scripts

## Deployment prerequisites

1. Apply the 0.4.0 versioned installer to a verified 0.3.6 source tree.
2. Refresh backend dependencies to install `cryptography`.
3. Apply the CRM and permission migrations.
4. Run the explicit Phase 4 company initializer.
5. Restart Django and Next.js.
