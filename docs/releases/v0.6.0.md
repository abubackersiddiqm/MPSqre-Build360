# MPSqre Build360 v0.6.0

Phase 6 adds tenant-scoped vendor qualification, purchase requests, RFQs, vendor quote comparison, purchase-order award, goods receipts, inventory catalogues, warehouses, append-only stock ledger, concurrency-safe stock balances, audit evidence, outbox facts, semantic permissions, and the Supply workspace.

Local development remains compatible with the native Windows no-Docker mode. Production must use shared cache, workers, managed PostgreSQL, and governed object storage.
