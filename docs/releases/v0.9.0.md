# MPSqre Build360 v0.9.0

Phase 9 adds provider-neutral communication requests, per-channel policy,
consent history, quiet hours, immutable published templates, signed provider
callbacks, inbound communication review, notification rules, user preferences,
and an in-app notification inbox.

The release preserves the native Windows/no-Docker development mode. In that
mode, in-app delivery is active and an optional local no-op adapter can be used
for deterministic external-channel testing. No production email, SMS,
WhatsApp, or voice provider is enabled automatically.
