# MPSqre Build360 0.3.5 — Local Backend Service Host Repair

## Defect

Host-based Django inherited Docker-only service names such as `redis:6379`.
Those names resolve inside the Docker Compose network but not from Windows.
DRF throttling touches the Redis cache before credential validation, causing
`POST /api/v1/auth/token` to return HTTP 500.

## Resolution

- Adds an idempotent backend `.env` repair utility.
- Converts only backend host-development endpoints to `127.0.0.1`.
- Preserves the project-root `.env` for Docker Compose.
- Creates a timestamped backup before changing backend `.env`.
- Adds a backend launcher that clears stale shell variables before loading `.env`.
- Adds a Redis environment/connectivity test.
- Updates local backend setup to normalize an existing backend `.env`.

## Database impact

None.
