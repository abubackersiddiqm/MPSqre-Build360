# MPSqre Build360 v0.11.0

Phase 11 introduces the governed AI bounded context and `/ai-control`
workspace. It adds provider/model policy governance, permission-aware grounded
summaries, citations, extraction review, advisory risk signals, human-confirmed
tool proposals, and evaluation evidence.

The release remains compatible with the native Windows/no-Docker development
profile. No external AI provider or autonomous tool executor is enabled.
