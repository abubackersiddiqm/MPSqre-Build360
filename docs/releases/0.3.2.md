# MPSqre Build360 0.3.2

## Purpose

This cumulative local-development hotfix resolves three startup gaps after the
Phase 3 upgrade:

- Django now loads a deterministic `.env` file automatically.
- Pinned `requirements.txt` and `requirements-dev.txt` files are supplied.
- PostgreSQL and Redis are published only on loopback for host-based Django commands.

It also includes the 0.3.1 health-view routing correction and adds
`python-dotenv==1.2.2` to the canonical project dependency metadata.

## Environment resolution

Existing process variables have highest precedence. When no process value is
present, Build360 loads one file in this order:

1. `DJANGO_ENV_FILE`
2. `backend/.env`
3. project-root `.env`

## Local installation

Use the release-root `Setup-Local-Backend.bat` utility to rebuild the Python 3.14
virtual environment, install the pinned development dependencies, and prepare a
host-safe `backend/.env` without printing secrets.
