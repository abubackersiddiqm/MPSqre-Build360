# MPSqre Build360 v0.14.0

Phase 14 introduces the Globalization and Integration Hub.

## Added

- Eight regional localization templates for India, UAE, Saudi Arabia, Singapore, Australia, UK, USA and Canada
- Versioned localization publication with SHA-256 evidence
- Append-only exchange-rate snapshots
- Provider-neutral integration connector profiles
- One-time API client secret issuance and rotation
- Governed webhook subscriptions and delivery simulation evidence
- Versioned data mappings and idempotent synchronization runs
- Integration workspace at `/integrations`
- Twenty-two semantic integration permissions

## Safety posture

- No external connector is activated automatically
- Secret values are represented by secret references
- Webhook simulations do not perform external network requests
- Raw API client secrets are returned only once
- Existing native-Windows no-Docker operation remains unchanged
