# MPSqre Build360 v0.10.0

Phase 10 introduces governed reporting and exports, client/vendor portal access, validation-first imports, privacy request workflows, effective-dated retention policies, and recovery-verification evidence.

## Deployment

- Required baseline: v0.9.0
- Database migrations: reporting, portal, dataops and identity permission seed
- Runtime: native Windows/no-Docker development remains supported
- No new Python or Node dependency is introduced

## Security controls

- Tenant-scoped report execution and export downloads
- SHA-256 export integrity checks and expiry
- Portal invitation token digests and email-bound acceptance
- Portal permission allow-lists and bounded record shares
- Validation preview before import commit
- Audit and transactional outbox evidence for material operations
